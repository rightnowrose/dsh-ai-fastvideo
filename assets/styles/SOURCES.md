## 「代码动画」哔哩哔哩 俯仰观照 的约定（A–G / R / M / K / Z / H / O 七类）

原库 `许可与来源.md` 原文：

> 约定：免费使用，转发也请免费分享；**禁止包装成课程、付费 skills 或其他收费产品出售**。

本插件据此分发：

- 本插件本身 **MIT 开源、免费**，不收费、不带任何付费入口；
- 风格库随包分发、可自由查看与修改，但**不得**拆出来做成付费课程 / 付费 skills / 付费素材包出售；
- 二次分发请保留本文件、`assets/licenses/` 与风格 `.md` 里的原始署名信息。

## 本插件没有随包分发的东西

- 表情包（maid 系列 322 张 GIF）：仅在本机使用时从 `stickersDir` 读取；
- BGM 素材：从 `bgm.file` 读取，不随包；
- 自训练音色（GPT-SoVITS）：不随包，需要自己配置；
- 任何 API key：不随包，写在 `<dataDir>/config.json` 里。

## 新增风格时

往 `assets/styles/<分类>/` 放一个 `.md`（同名 `.jpg` 可选），面板 60 秒内或点一次「刷新」就能看到；
批量导入见 `scripts/import_styles.py`。若你的风格来自别处，请把它的来源与许可补进本文件。
